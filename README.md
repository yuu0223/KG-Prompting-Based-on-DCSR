# Enhancing Knowledge Graph Prompting for Large Language Models Based on Densely Connected Subgraph Retrieval
本研究旨在透過檢索知識圖譜來增強大型語言模型在專業領域中的推理能力及可解釋性。我們透過 Densely Connected Subgraph Retrieval 找出關聯緊密的子圖，並將圖狀結構的 subgraph 轉換為線性的 paths，最後，搭配 prompt engnnering 來引導 LLM。

This study aims to improve the reasoning ability and explainability of LLMs in professional domains through KG prompting. We leverage Densely Connected Subgraph Retrieval to extract structurally cohesive and semantically relevant subgraphs, transform them into linear paths, and subsequently convert them into natural language to guide LLMs via prompt engineering.
